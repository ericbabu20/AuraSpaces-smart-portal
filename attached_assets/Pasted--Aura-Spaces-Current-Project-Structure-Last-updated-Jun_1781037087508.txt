# Aura Spaces — Current Project Structure

Last updated: June 2026

This document describes the **current state of the `aura-spaces` repository**, including the active Next.js web app, legacy Expo prototype files, database assets, and the Next.js build output.

---

## Quick summary

| Area | Status |
|------|--------|
| **Active web app** | Next.js 15 (App Router) |
| **Marketing site** | `/` — Aura Energy Assistant landing page |
| **Home dashboard** | `/home/*` — Stitch-based smart-home UI (10 screens) |
| **Legacy mobile app** | Expo/React Native files kept in repo, not part of active Next build |
| **Database** | Supabase migrations + seed (Phase 1 foundation) |
| **Build output** | `.next/` (generated; do not edit manually) |

---

## How to run

```bash
npm install
npm run dev
```

Recommended on macOS if file watching fails:

```bash
WATCHPACK_POLLING=true npm run dev -- -H 127.0.0.1 -p 3000
```

Other scripts:

| Script | Purpose |
|--------|---------|
| `npm run build` | Production build → `.next/` |
| `npm run start` | Serve production build |
| `npm run lint` | ESLint (active web files only) |
| `npm run typecheck` | TypeScript check |
| `npm run test` | Vitest (configured, minimal tests so far) |

Environment template: `.env.example`

## `.next/` build folder

Created by `npm run dev` or `npm run build`. **Do not commit or edit manually.**

```text
.next/
├── cache/                        # Webpack, SWC, ESLint caches
├── server/                       # Server bundles
│   └── app/
│       ├── (site)/               # Marketing routes
│       └── home/                 # Dashboard routes
├── static/                       # Client JS, CSS, fonts, media
│   ├── chunks/
│   ├── css/
│   └── media/
└── types/                        # Generated route types
```

After `npm run build`, Next.js also emits optimised static pages for all 15 app routes listed in the build output.

## Configuration files

| File | Purpose |
